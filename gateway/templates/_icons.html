{# Platform marks, as inline SVG. Inline because `base.html` has to render in a cluster that cannot reach a CDN, so an icon font or a remote sprite would leave the panel unlabelled exactly when something is wrong with the network. Simplified glyph forms rather than the official brand files: the shapes are what makes them recognisable at this size, and a 20px badge does not carry gradient lockups. `currentColor` throughout, so an icon always matches the badge or the switcher entry it sits in and there is one colour to change. The word is always rendered next to these. Colour and shape are a finding aid, never the only thing distinguishing one board from another. #} {% macro platform_icon(platform, size=13) -%} {%- if platform == 'youtube' -%} {%- elif platform == 'facebook' -%} {# The lowercase f in its rounded square, drawn as an outline so it sits in the same weight as the other three rather than as the only solid mark. #} {%- elif platform == 'tiktok' -%} {# A quaver, which is the shape the eye finds at this size. The official mark is two offset copies in two colours, which at 13px reads as a smudge and cannot be drawn in currentColor. #} {%- else -%} {%- endif -%} {%- endmacro %} {# The word beside the mark, in one place. It lived as `{'youtube': 'YouTube', 'tiktok': 'TikTok'}.get(p, 'Instagram')` in two templates, which was two copies of a list that grows every time a destination is added and no way to notice when only one of them did. The fallback is still Instagram rather than the raw column, for the reason the account readers default to it: a platform nobody has taught this about renders the word that has always been rendered. #} {% macro platform_name(platform) -%} {{- {'youtube': 'YouTube', 'tiktok': 'TikTok', 'facebook': 'Facebook'} .get(platform, 'Instagram') -}} {%- endmacro %} {# What each page in the sidebar is for, as a shape next to the word. Outlines in the same weight as the platform marks, in currentColor, so an icon takes the link's colour and lights with it. Never on its own: the label is always beside it, and a screen reader skips the mark. #} {% macro nav_icon(name) -%} {%- endmacro %}
