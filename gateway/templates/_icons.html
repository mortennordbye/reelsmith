{# Platform marks, as inline SVG. Inline because `base.html` has to render in a cluster that cannot reach a CDN, so an icon font or a remote sprite would leave the panel unlabelled exactly when something is wrong with the network. Simplified glyph forms rather than the official brand files: the shapes are what makes them recognisable at this size, and a 20px badge does not carry gradient lockups. `currentColor` throughout, so an icon always matches the badge or the switcher entry it sits in and there is one colour to change. The word is always rendered next to these. Colour and shape are a finding aid, never the only thing distinguishing an Instagram board from a YouTube one. #} {% macro platform_icon(platform, size=13) -%} {%- if platform == 'youtube' -%} {%- else -%} {%- endif -%} {%- endmacro %}
